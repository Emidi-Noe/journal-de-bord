<h1> Les commandes utilisé aujourd'hui</h1>
    Initialise le dépot git <pre> git init</pre> <br>
    Montre l'état actuel de la zone de travail <pre> git status</pre><br>
    Montre un historique des dernières modification <pre>git log</pre><br>
    Rajoute un document à la zone de travail <pre>git add diplome.txt </pre><br>
    Envoie la zone de travail dans le repertoire , afin de mettre a jours les éléments <pre>git commit</pre><br>
    Montre les différence entre les commit <pre>git diff</pre><br>
    Permet de créé une branche ou de la déplacer vers une autre <pre>git branch 'uneBranche'</pre>
